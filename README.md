### 2.5 Main Body Sections

Introduction to AI and Machine Learning

Artificial Intelligence (AI) enables machines to perform tasks that typically require human intelligence. Machine Learning (ML) is a subset of AI that allows systems to learn patterns from data. Deep Learning uses multilayer neural networks to learn complex representations.

These technologies provide the foundation for Generative AI, which learns data patterns to generate new outputs.
What is Generative AI?
Generative AI is a type of artificial intelligence that generates new content based on patterns learned during training. It can produce text, images, music, videos, and programming code.

For example, when a user enters the prompt “Explain cloud computing,” a generative language model produces a relevant explanation based on its learned patterns.

The general process involves data collection, preprocessing, model training, user prompting, content generation, and output evaluation.
Types of Generative AI Models

Model	Working principle	Applications

GANs	A generator creates samples while a discriminator evaluates them	Image synthesis and realistic visual content

VAEs	An encoder learns a latent representation and a decoder generates samples	Data generation and representation learning

Diffusion models	Generate data by gradually removing noise	Image generation and editing

Autoregressive models	Predict the next element in a sequence	Text generation and language modelling

Transformers	Use attention mechanisms to process contextual relationships	LLMs, chatbots, and code assistants

Introduction to Large Language Models (LLMs)

Large Language Models are neural networks trained on large quantities of text or other tokenized data. They learn language patterns and generate responses based on user inputs.

Examples include GPT, BERT, T5, and Llama. GPT-style models are commonly used for text generation, while BERT was originally designed primarily for language understanding tasks.

Architecture of LLMs

The Transformer architecture contains tokenization, embeddings, positional information, attention layers, feed-forward networks, and output layers.

The self-attention mechanism helps a model determine how different tokens relate to one another. GPT-style models commonly use causal attention to predict subsequent tokens, while BERT uses bidirectional context to learn text representations.

A simplified workflow is:

Input Text → Tokenization → Embeddings → Transformer Layers → Output Probabilities → Generated Text

Training Process and Data Requirements

LLM training generally includes the following stages:

1. Data collection from suitable text and other permitted sources.

2. Data preprocessing to remove duplicates and improve data quality.

3. Tokenization to convert text into numerical tokens.

4. Pre-training to learn general patterns from the data.

5. Fine-tuning to improve performance on particular tasks.

6. Evaluation to assess accuracy, usefulness, safety, and reliability.

The quality of training data is important because incomplete, inaccurate, or biased data can affect model performance.
Use Cases and Applications

Generative AI has applications in many fields:

- Education: Generating explanations, quizzes, and study materials.

- Healthcare: Summarizing medical literature and supporting documentation.

- Software development: Generating code, explaining errors, and assisting debugging.

- Business: Drafting reports, emails, and presentations.

- Finance: Extracting invoice information and assisting document analysis.

- Content creation: Generating articles, images, designs, and multimedia content.

Human verification is important when outputs affect medical, financial, legal, or other high-impact decisions.

Limitations and Ethical Considerations

Generative AI may produce inaccurate information, reproduce biases, expose sensitive information, or generate content that raises copyright concerns. Training and operating large models can also require substantial computational resources.

These challenges can be addressed through data-quality checks, privacy safeguards, security testing, output verification, bias evaluation, and human oversight.
Future Trends
Future developments in Generative AI include multimodal systems that process text, images, audio, and video; smaller and more efficient models; retrieval-augmented generation (RAG); AI agents; and explainable AI systems.

These technologies may improve accessibility, productivity, and the reliability of AI-assisted workflows when implemented responsibly.
